## 🛠️ Figma에서 편집 가능한 레이어로 여는 방법 (1분 완성)

### 🌟 방법: Figma 'html.to.design' 플러그인 이용
Figma에서 **글자 수정, 컴포넌트 분리, 오토레이아웃(Auto Layout)**이 100% 살아있는 실제 피그마 레이어로 변환됩니다.

1. **Figma** 실행 후 새 파일(캔버스) 열기.
2. `Ctrl + /` (Mac은 `Cmd + /`)를 눌러 검색창에 **`html.to.design`** 입력 후 플러그인 실행.
3. 플러그인 상단에서 **[File]** 탭 (또는 HTML File Upload) 선택.
4. `export-figma/` 폴더 안의 HTML 파일들을 드래그 앤 드롭.
5. **[Import]** 클릭 즉시 Figma 캔버스에 100% 수정 가능한 프레임으로 생성됩니다.
